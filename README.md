# ExchangeMap

**ExchangeMap** es una plataforma web interactiva y moderna diseñada para estudiantes universitarios y académicos que buscan realizar un intercambio internacional. Permite explorar el mundo a través de un mapa interactivo visual, consultar requisitos académicos, procesos de visado, costos estimados de vida, universidades de destino y testimonios/experiencias.

---

##  Características Principales

- **Mapa Mundial Interactivo**: Visualización fluida con selección por países, códigos de color según requisitos de visa y convenios universitarios.
- **Requisitos Académicos Detallados**: GPA mínimo, certificaciones de idioma (TOEFL, IELTS, DELE, etc.), áreas de estudio y programas elegibles.
- **Guía de Visas y Trámites**: Requisitos de visa de estudiante, solvencia económica requerida, tiempos estimados de procesamiento y enlaces oficiales de embajadas.
- **Estimador de Costo de Vida**: Comparativa de gastos promedio mensuales (alojamiento, alimentación, seguro médico, transporte).
- **Directorio de Universidades**: Listado de instituciones aliadas por país con rankings, facultades y periodos de postulación.
- **Filtros Avanzados y Comparador**: Filtra por idioma, continente, costo, o compara 2 a 3 países/destinos lado a lado.
- **Diseño Moderno y Responsivo**: Interfaz moderna (dark/light mode, micro-animaciones, estética glassmorphic y optimización mobile-first).

---

## Stack Tecnológico Propuesto

- **Frontend**: React + Vite con TypeScript
- **Estilos**: Vanilla CSS moderno con variables de diseño, glassmorphism y animaciones fluidas
- **Visualización de Mapas**: Leaflet / React-Leaflet con GeoJSON optimizado
- **Iconografía**: Lucide Icons
- **Gestión de Estado y Datos**: React State / Context con catálogo inicial enriquecido de países e instituciones
